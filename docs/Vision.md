# Vision

I am learning LLM coding best practices by building a simple tool that runs in the Mac Terminal, accepts a user-entered prompt, sends it to an LLM, and displays the response.

The primary purpose of this project is to learn good AI-assisted software engineering practices. The resulting tool is a vehicle for that learning, not the end goal.

We will work incrementally, favor human-readable code appropriately sized to the task, make small changes, explain significant decisions clearly, and maintain human oversight of implementation.
